## 2. PDF 대조 결과

### 일치 확인
- 각주 「제4조(전담부서의 설치ㆍ운영 등)」 전문 = 2215665 의안원문 제4조 전문(글자 단위 100% 일치)
- 각주 「정부조직법」 제2조제4항 = 행안위 검토보고 21쪽 각주 23)
- 표 `이용중지/긴급차단 비교`: 1∼3일·10분 이내·7일 이내 = 행안위 검토보고 36쪽
- 표 `전화번호 차단 요건`·`긴급차단 기간`의 2215665 항목(제5조제2항 요건, 제5조제3항 최대 7일) = 의안원문
- 「입법 필요성」 각주(35쪽), 긴급차단 시작시점 각주(2025. 10. 30., 33쪽) = 행안위 검토보고
- 신·구조문대비표 `제2조의7` 현행 ①∼④ = 행안위 검토보고 11쪽 인용 조문

### 불일치 → 수정한 것
- 행정안전부 의견 각주 쪽수 33쪽 → **21쪽**, 의견 내용에 "해당 조항 삭제" 및 "통합대응단에서 기수행" 반영
- 현행법 제4조제1항 사유 열거의 중복 번호 ④ → ⑤

### 불일치 → 수정하지 않고 병기한 것
- 통합대응단 인원/파견기관: 본문 134명·금융보안원 포함 vs 행안위 검토보고 135명·금융소비자보호원 포함(11명 파견). 기준시점이 달라 단정하지 않고 병기함.
